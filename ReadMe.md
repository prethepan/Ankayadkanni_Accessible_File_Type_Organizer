# Ankayadkanni File Organizer

> **Filename:** `README.md`

## Overview

**Ankayadkanni File Organizer** is a simple and accessible Windows desktop application designed to help users automatically organize files into folders based on file type. It is especially useful for users who want a fast, keyboard-friendly way to keep their folders clean and well structured.

The application is packaged as a Windows installer (**MSI**)

---

## Key Features

* Organizes files automatically by extension (example: PDF, DOCX, MP3, JPG)
* Simple user interface
* Keyboard-friendly operation
* Screen reader–friendly behavior
* Desktop shortcut created during installation
* Start Menu shortcut created during installation
* Clean uninstall (no leftover files or shortcuts)

---

## System Requirements

* Operating System: Windows 10 or later (64-bit recommended)
* No additional runtime required 
* Administrator permission required for installation (per-machine install)

---

## Installation Instructions

### Normal Installation

1. Download the file:
   **Ankayadkanni_File_Organizer.msi**
2. Press **Enter** on the MSI file
3. Follow the Windows Installer prompts
4. After installation, shortcuts will be available:

   * Desktop
   * Start Menu

---

## How to Use the Application

1. Open **Ankayadkanni File Organizer** from Desktop or Start Menu
2. Select or provide the folder path to organize
3. Run the organizer
4. Files will be moved into folders based on their file types

Example:

* PDF files → PDF folder
* Images → Images folder
* Audio files → Audio folder

---

## Accessibility

This application is designed with accessibility in mind:

* Works well with screen readers (NVDA, JAWS)
* Supports full keyboard navigation
* No reliance on mouse-only actions

---

## Uninstallation

### Normal Uninstall

1. Open **Settings → Apps → Installed Apps**
2. Find **Ankayadkanni File Organizer**
3. Select **Uninstall**

---

## Known Limitations

* Files currently in use may not be moved
* Administrator permission is required for installation
